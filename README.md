# Working of Controllers
# #1.TM1637 Quad Seven-Segment Display

A bare-metal / C++ implementation to control a 4-digit 7-segment display using the TM1637 driver chip.

---

###📌 Project Overview

This project demonstrates how to interface a microcontroller with a **TM1637 4-digit 7-segment display**. It covers low-level bit-banging and register manipulation to control segment data and clock lines.
